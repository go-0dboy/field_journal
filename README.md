# Полевой дневник

Android-приложение на Kotlin для археологических и исторических наблюдений. Требуется Android 8.0 или новее.

[Скачать APK](https://github.com/go-0dboy/field_journal/releases/download/android-preview/Field-Journal.apk) · [GitHub Actions](https://github.com/go-0dboy/field_journal/actions/workflows/android.yml)

## Работа в поле

- **Карта.** Откройте «Слои» для переключения схемы, спутника или гибрида. Схема использует OpenStreetMap, спутник, дороги и подписи гибрида — Esri. Для схемы можно указать свой HTTPS-источник XYZ. Масштаб, положение карты и режим сохраняются.
- **Местоположение.** Значок геолокации у нижнего края карты запрашивает координаты Android. Телефон может использовать GPS, ГЛОНАСС и другие поддерживаемые системы GNSS, а также сеть, Wi‑Fi и объединённый поставщик Android. Приложение показывает оценку точности и поставщика, который выдал координаты. Высота спутникового решения относится к эллипсоиду WGS 84.
- **Точка.** Коснитесь места на карте или сдвиньте карту под прицелом, затем нажмите «Установить». Кнопка «Координаты» открывает окно с выбранной точкой или центром карты и действием «Скопировать». В основном меню карты в том же окне можно ввести координаты вручную.
- **Область.** Поставьте вершины касаниями карты или кнопкой «Добавить» под прицелом. Касание вершины удаляет её, а удержание позволяет перетащить. «Удалить» снимает последнюю вершину. Кнопка «Готово» проверяет и сохраняет замкнутый контур.
- **Карточка.** Запишите датировку, культурную принадлежность, состояние, происхождение координат, номер учёта, автора, контекст и источники. Добавьте фото с камеры или из телефона, документы и ссылки. Доступны поиск и фильтр по типу. Галочка и выход из карточки с правками открывают подтверждение сохранения. Выберите «Сохранить», «Не сохранять» или «Отмена». Краткие подсказки всплывают внизу над кнопками. При ошибке записи можно повторить сохранение, оставив введённые данные на экране.
- **Дневник.** Запись может содержать дату, время, автора, погоду, описание работ и вложения. Её можно связать с карточкой. Если открыть запись из объекта, кнопка «Назад» вернёт в этот объект.

Справочник различает стоянки, селища, городища, курганы, курганные группы, могильники, места находок, раскопы, урочища, сооружения и дороги. Пиктограммы учитывают образцы топографической легенды для курганов и захоронений (№ 343 и № 69). Другие типы имеют собственные знаки приложения. См. [условные знаки топографических планов ГУГК](https://ggspb.org/normativnaya-baza/files/uslovnye-znaki-dlia-topograficheskikh-planov-masshtabov-5000-2000-1000-500.pdf).

## Исторические карты и гибрид

В меню «Слои» нажмите «Подключить MBTiles» под заголовком «Историческая карта». Приложение откроет район покрытия. Этот слой можно включать поверх схемы, спутника или гибрида, менять его непрозрачность и возвращаться к нему кнопкой «К участку». Подключён один исторический файл. Его можно заменить прямо в меню «Слои».

Гибрид рисуется в таком порядке. Внизу находится спутник, затем идёт историческая карта, если она включена, поверх неё — современная дорожная сеть и названия, а выше всех — точки и области дневника. Прозрачный слой современных обозначений можно включить и поверх исторической карты на других подложках. Наполнение дорог и названий зависит от масштаба и покрытия источника.

Если исходник — скан, сначала геопривяжите его по опорным точкам, например в QGIS, затем экспортируйте растровые MBTiles в Web Mercator (EPSG:3857). Выберите масштаб, соответствующий детализации скана. Карты устанавливаются из файлов пользователя.

## Работа без Интернета

В разделе «Данные и карты» подключите растровый файл **MBTiles** для нужного слоя. Приложение копирует его в собственное хранилище и открывает область пакета. Для схемы, спутника и гибрида могут быть подключены разные файлы. После установки подложки, например перед выездом, переключитесь в офлайн и проверьте нужный участок на нескольких масштабах.

Поддерживаются PNG, JPEG и WebP в Web Mercator по [спецификации MBTiles](https://github.com/mapbox/mbtiles-spec/blob/master/1.3/spec.md). Офлайн-гибрид использует свой пакет MBTiles, а если его нет — пакет спутника. Чтобы подписи оставались поверх исторической карты в офлайне, подключите отдельный прозрачный MBTiles с дорогами и названиями в «Данные и карты» → «Офлайн · дороги и подписи» (PNG или WebP с альфа-каналом). MBTiles можно подготовить в QGIS из материалов, условия которых разрешают локальные копии. Стандартные тайлы OpenStreetMap используются для интерактивного просмотра согласно [правилам OSMF](https://operations.osmfoundation.org/policies/tiles/). Встроенные онлайн-подложки в MBTiles не выгружаются.

## Данные и перенос

Новые объекты и записи открываются как черновики. Они появляются в SQLite после подтверждения сохранения. Фотографии и документы копируются в закрытое хранилище приложения. Дополнительная локальная копия метаданных обновляется автоматически. Для переноса на другой телефон или восстановления после удаления приложения сохраните **ZIP** через «Экспорт резервной копии».

- **ZIP** содержит карточки, записи дневника и вложения. Пакеты карт подключаются отдельно. Предел для ZIP и для суммарного объёма вложений составляет 2 ГиБ. Приложение сначала подготавливает архив во временном хранилище и проверяет лимиты.
- **GeoJSON** содержит объекты WGS 84 с точками, полигонами и полями карточек. Можно отдавать каталог в ГИС и импортировать подготовленные извне файлы с геометриями Point и Polygon, в том числе полигоны с внутренними контурами. Для сторонних GeoJSON полезно указывать стабильный `id` и `properties.title` или `name`. Приложение принимает один Feature или целую FeatureCollection.
- Импорт добавляет записи и сохраняет уже существующие ID. ZIP проверяется до фиксации данных. Дневник и медиа переносятся в ZIP.

## Сборка

JDK 17, Android SDK 35, Build Tools 35.0.1, Gradle Wrapper 8.9.

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

GitHub Actions собирает и проверяет подпись APK. В каждом успешном запуске сборка доступна как артефакт **Field-Journal-APK**. Сборки ветки `main` дополнительно публикуются в предварительном выпуске `android-preview`.

Для предварительной сборки Actions сохраняет отладочный ключ в кэше. Для устойчивых обновлений между сборками задайте собственный ключ через секреты `FIELD_JOURNAL_KEYSTORE_BASE64`, `FIELD_JOURNAL_STORE_PASSWORD`, `FIELD_JOURNAL_KEY_ALIAS`, `FIELD_JOURNAL_KEY_PASSWORD`. APK с другой подписью Android не установит поверх существующего. В этом случае сохраните ZIP из приложения перед переустановкой.
